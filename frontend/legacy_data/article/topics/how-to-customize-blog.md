## 零、第一步：把图纸复印到自己的背包里 (Fork 仓库)

萌新小伙伴请注意啦！直接 Clone 风酱的原始仓库是**错误的起点**哦 ❌。\
你需要先把项目 **Fork**（也就是复印一份图纸）到你自己的 GitHub 账号下，然后对自己的那份图纸进行修改和部署。\
这样一来，你的魔改就不会和原仓库打架，以后想把代码挂到服务器上也会超级方便哒！

**🪄 施法步骤：**

1. 打开 [原始仓库页面](https://github.com/futurelesswindchan/blog0fwindchan)，看到 Star 左边的 **Fork** 按钮了吗？请狠狠戳击 TA ！ σ`∀´\)σ
2. 选择你自己的 GitHub 账号作为目标，点击 **Create fork**。
3. 叮！复印完成！现在请 Clone **你自己的 Fork 仓库**（一定要注意 URL 里换成了你的用户名哦）：

```bash
git clone https://github.com/<你的GitHub用户名>/<你的Fork仓库名>.git
cd <项目文件夹名>
```

4. 接着按 README 里的本地开发步骤，在本地把博客跑起来就好啦。

好耶！现在你拥有了一份完全属于自己的代码库，可以放开手脚随便折腾啦！不用怕弄坏，坏了咱大不了重新 Fork 一次！(๑•̀ㅂ•́)و✧

## 一、寻宝透视镜：Vue DevTools 🔍

在开始装修前，风酱先送你一个找代码的“外挂”法宝。

当你用 `npm run dev` 启动前端后，去看看浏览器页面的右下角（或者底部），是不是躲着一个 Vue 的小图标？——这就是强大的 **Vue DevTools** 啦！
点击它，进入组件树视图，你就可以直接在页面上点选任何你感兴趣的 UI 元素，这个法宝会自动帮你定位到对应的 `.vue` 文件，并且在 VSCode 里直接打开它哦！

如果你不知道某段文字或者样式藏在哪个文件里，用这个透视镜点一下，绝对比你在目录里苦翻要快上一百倍呢！owo✨

## 二、核心装修区：站点配置文件 📝

**博客里绝大部分的个性化文字和信息，都乖乖地集中在这个文件里等你去改哦：**`frontend/src/site.config.ts`

打开它，你会看到下面这几个配置小方块。挨个把它们换成你自己的信息吧！

### 2.1 你的站点大名

```ts
export const siteConfig = {
  title: '风风博客', // 👈 把它换成你超酷的博客名吧！
}
```

### 2.2 首页的自我介绍

```ts
export const homeInfo = {
  pageTitle: 'Blog Of Windchan', // 首页最醒目的大标题
  nickname: '没有未来的小风酱', // 替换为你的专属昵称
  statusText: '正在摸鱼中awa...', // 这是头像旁边的小状态
  sloganText: '唔...这都被你发现啦？', // 那个一字一字敲出来的打字机特效文字在此~
  sloganSub1: '欢迎来到风风的赛博小屋...', // 副标题第一行
  sloganSub2: '⬆️联系方式⬆️ 欢迎交流', // 副标题第二行
}
```

### 2.3 社交传送门 (联系方式)

```ts
export const socialLinks: SocialLink[] = [
  {
    name: 'GitHub',
    icon: 'fab fa-github',
    link: 'https://github.com/<你的用户名>', // 👈 换成你自己的主页链接哦
    color: '#24292e',
  },
  // Bilibili 和 Email 等其他平台也是同样的操作~
]
```

> 💡 图标使用的是 [FontAwesome](https://fontawesome.com/icons) 的魔法类名，你可以去他们官网搜索你喜欢的图标然后替换掉。´-ω-\)b

### 2.4 首页的大卡片传送门

```ts
export const portalItems: PortalItem[] = [
  {
    icon: 'fa-laptop-code',
    title: '技术手札', // 卡片上的大字
    desc: '代码与Bug的爱恨情仇', // 卡片下面的小字描述
    route: '/articles/frontend', // 跳转路径，通常不需要改它哦
  },
  // 其他卡片也是一样的改法~
]
```

### 2.5 文章分类名称与描述

```ts
export const ARTICLE_CATEGORIES: ArticleCategory[] = [
  {
    id: 'frontend',
    title: '技术手札',
    desc: '这里是咱的开发笔记与心得...',
    // ...
  },
  // 其他分类同理
]
```

> ⚠️ **风酱的特别提醒**：这里的 `id` 和 `routeName` 字段必须和数据库里分类的 `slug` 对应上哦！\
> 如果你改了它们，记得要去数据库里同步更新分类数据，不然文章列表会迷路找不到内容的 QAQ！\
> 如果只是想改页面上显示的文字，那只改 `title` 和 `desc` 就好啦。

## 三、给小屋换上新壁纸和头像 🖼️

这些漂亮的图片资源的家在 `frontend/public/assets/images/` 目录下。想要换上你自己的图，只需要直接替换掉对应位置的文件就可以啦。\
**但是千万要注意：文件名必须保持一模一样哦！**

| 文件名                                 | 它的职责是...                |
| :------------------------------------- | :--------------------------- |
| `logo.webp`                            | 你的专属头像 + 导航栏的 Logo |
| `wallpaper.webp`                       | 亮色模式下的背景壁纸         |
| `dark-theme-wallpaper.webp`            | 暗色模式下的背景壁纸         |
| `favicon.png`（躲在 `public/` 目录下） | 浏览器标签页上的那个超小图标 |

> 💡 **小贴士**：非常推荐大家使用 `.webp` 格式的壁纸，体积小加载又快！壁纸的分辨率建议最好不要低于 1920×1080，这样看起来才够清晰哦。
>
> 🛑 **版权防雷指南**：README 里预览的两张壁纸因为版权原因没有包含在代码库里，你需要自己准备好看的图片。\
> 另外，**记得把默认的头像替换成你自己拥有版权的图片哦**，不要拿风酱画的神秘像素画去公网当站长啦 awa！

## 四、挥舞画笔：修改主题色 🖌️

博客里的高亮、按钮、发光特效等视觉元素，全靠一个文件来控制：

`frontend/src/styles/theme/theme.css`

打开它，在文件最顶部的 `:root` 魔法阵里找到下面这几个变量：

```css
/* 💙 博客的核心主题色 */
--accent-color: #0077ff; /* ☀️ 亮色模式下的主题色 */
--accent-color-rgb: 0, 119, 255; /* 对应的 RGB 值，必须和上面保持一致哦 */
--dark-accent-color: #1a85ff; /* 🌙 暗色模式下的主题色 */
--dark-accent-color-rgb: 26, 133, 255;
```

只需要修改这四个变量的值，就能一键全局换肤啦！\
（为什么需要 `-rgb` 变量呢？因为有些地方需要做半透明效果呀~比如 `rgba(var(--accent-color-rgb), 0.5)`，所以记得要保证 RGB 值和十六进制的颜色对得上哦 =w=）

## 五、精雕细琢：修改导航栏与页面标题 🏷️

### 🧭 导航菜单

导航栏的文字也藏在刚刚那个 `site.config.ts` 里。找到 `navItems` 数组，修改 `label` 字段就能给它们改名啦：

```ts
export const navItems: NavItem[] = [
  { path: '/home', label: '这是首页', ... },
  { path: '/articles', label: '文章导航', ... },
  // ...
]
```

### ⌨️ 页面顶部的打字机标题

当你切换页面时，浏览器标签页的标题，还有页面上方“哒哒哒”打字的特效文字会跟着变化。这些调皮的文字藏在路由配置里哦：

`frontend/src/router/index.ts`

找到 `routes` 数组，修改每个路由里面的 `meta.title` 字段就可以啦：

```ts
{ path: 'home', meta: { title: '欢迎回家...' } }
{ path: 'articles', meta: { title: '这里是全部的文章哦' } }
```
