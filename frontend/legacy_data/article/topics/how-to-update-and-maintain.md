# 🧹 3. 日常维护：如何长久地照顾你的赛博盆栽 (更新与维护指南)

> **🎯 目标园丁**：已经成功完成生产部署，现在需要把本地写好的新代码、新功能同步到线上服务器的站长大大们。

把博客部署上线只是第一步，它就像一盆可爱的赛博盆栽，偶尔也是需要你来浇浇水（更新代码）、剪剪枝（排查 Bug）的哦！\
别担心，日常养护的步骤超级简单~

---

## 一、标准浇水流程 (本地修改 → 云端同步)

核心思路永远是：**在本地小电脑上改好 → 推送到 GitHub → 让服务器自己去拉取 → 重启服务生效**。

### 第 1 步：把本地的心血打包送到云端

在本地写完新代码后，先把它们推送到你的 GitHub 仓库：

```bash
git add .
git commit -m "描述一下你这次做了什么超酷的更新awa"
git push origin main
```

> 💡 去 GitHub 网页上确认一下，看到最新的代码已经躺在里面了，再进行下一步哦。

### 第 2 步：让服务器接收新包裹

登录到你的服务器，把刚刚推送到云端的新代码拉取下来：

```bash
ssh <你的用户名>@<你的服务器IP>
cd ~/<项目文件夹名>
git pull origin main
```

### 第 3 步：重塑前端橱窗 (如果你改了前端代码)

如果你修改了 `frontend/` 下的 Vue 文件、换了图片，或者改了 CSS 样式，就需要让前端重新打包一次：

```bash
cd frontend
npm install   # 除非你装了新的依赖包，否则这步可以跳过哦
npm run build
```

打包完成后，戳一下 Nginx 守卫，让他换上新的橱窗展示：

```bash
sudo systemctl reload nginx
```

### 第 4 步：给后端小马达换机油 (如果你改了后端代码)

如果你修改了 `backend/` 下的 Python 代码，就必须重启后端服务，新代码才会生效哦：

```bash
cd ~/<项目文件夹名>/backend
sudo systemctl restart blog
```

## 二、魔法师的随身咒语本 (CLI 命令速查)

后端所有的管理操作，都需要借助 `flask` 这根魔法棒。
**⚠️ 施法前摇：执行咒语前，请务必确认你站在了魔法阵（虚拟环境）里，并且在 `backend/` 目录下哦！**

```bash
cd ~/<项目文件夹名>/backend
source venv/bin/activate
```

| 咒语                   | 它的效果是...                                            |
| :--------------------- | :------------------------------------------------------- |
| `flask db init`        | 建表并写入默认分类（仅限搬家/首次部署时使用）            |
| `flask db fix`         | 检查并自动修复数据库表结构（改动表结构后升级博客必备！） |
| `flask admin create`   | 召唤一名新的超级管理员                                   |
| `flask admin reset-pw` | 强行重置某个管理员的密码                                 |

## 三、赛博急救箱 (常见问题排错)

### 🚨 更新后满屏都是 502 Bad Gateway？

别慌！这通常是因为后端服务在重启时摔了一跤（启动失败）。我们来捉拿报错的捣蛋鬼：

```bash
# 先看看服务现在是什么状态
sudo systemctl status blog

# 翻开错误日记本（只看最后 50 行）
sudo journalctl -u blog -n 50 --no-pager
```

顺着日志里的 `Traceback` 报错信息往下找，通常就能发现是哪里写错啦（比如少装了某个依赖，或者代码拼写错误）。\
在本地修好之后，重新走一遍上面的“标准浇水流程”就好啦！

### 🔑 糟糕！我把管理员密码忘了！

问题不大，风酱准备了备用钥匙。在服务器的 `backend/` 目录下激活虚拟环境，然后念出这句咒语：

```bash
flask admin reset-pw
# 接着按照终端的提示，输入你的用户名和新密码就可以啦~
```

### 👻 见鬼了！前端明明更新了，浏览器里还是旧版本？

呼呼~这其实不是 Bug 哦！而是你的浏览器太贪吃啦awa\
它悄悄把旧的页面缓存（藏）了起来。

绝招：在页面上按下强制刷新快捷键（ Windows 是 `Ctrl + Shift + R`，macOS 是 `Cmd + Shift + R` ），就能看到新页面啦！
如果强刷也没用，去服务器上确认一下 Nginx 守卫有没有睡着：

```bash
sudo systemctl reload nginx
```
